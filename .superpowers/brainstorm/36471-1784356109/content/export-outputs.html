导演台输出 — 三种产物

渲染视频 / AI参考帧 / 运镜数据

1

🎬 渲染视频片段

将导演台 3D 场景 + 运镜动画渲染为 MP4，直接成为时间线 clip

📐 分辨率: 1920x1080 🎞 帧率: 30fps ⏱ 时长: 与运镜时间线一致
🔧 实现：Orillusion canvas → MediaRecorder/FFmpeg → MP4 → 写入项目 assets 目录
2

🖼 AI 参考帧截图

截取当前 3D 视口画面，作为 AI 生成管线（如 ControlNet）的参考输入

🖼 PNG 格式 📐 视口分辨率 🎯 含深度通道(可选)
🔧 实现：Orillusion readback → Canvas.toDataURL → 写入文件 / 传递给 AI 节点
3
